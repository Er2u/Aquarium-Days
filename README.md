## 本次更新

- **海龟顺路收币。** 小海龟追逐可达的高面值金币，也会把沿途经过的小币收好。寻金虾优先找铜币。
- **饿倒的鱼还能抢救。** 鱼会在 15 秒内慢慢泛白、翻身。钱不够时，快捷栏用红色价格与金币图标提示。
- **存档与经营修复。** 修复召唤书确认、来信交付、幼鱼成交和探险收获轮次。保存遇到写盘错误时能在原局重试。
- **多鱼目录。** 鱼被捕食或移出时，鱼目录会更新对应的行。首次升级提示与打开存档页的停顿也已缩短。

## 下载、启动与存档

**Windows x64**　完整解压到新文件夹，双击 `Aquarium Days.exe` 并保留附带文件。v0.4.0 玩家可从符合当前读取规则的原槽继续。十月的 chapter01-rc1 及更早版本仍需从空槽开局。

**Apple Silicon Mac**　完整解压后运行 `Launch_Playtest.command`，或直接打开应用。脚本与应用使用同一常规存档位置。[Mac 启动说明](https://github.com/Er2u/Aquarium-Days/releases/download/v0.4.1-pre-alpha/README_M2_Playtest.md)

左键交互，数字键或小键盘 1–6 选择快捷栏，右键或 Esc 取消、返回。音量可在设置的音频页调整。

## 试玩数据

「分享试玩数据」默认开启，可以在 **设置 → 试玩数据** 关闭，重启后保留选择。收集有限的进度、功能使用、性能摘要与错误诊断，帮助定位卡点；不上传完整存档、自定义鱼名、账号或本机路径，使用随机安装与会话标识。

数据低频记录、后台上传，断网不阻止经营、保存或退出。关闭后停止采集与上传并清理本地待传队列，已送达的数据不会自动撤回。

## English

The **v0.4.1 pre-alpha** playtest covers Chapter 1 through the three-star award. The turtle now collects coins it passes while pursuing valuable ones, and shrimp prefer copper coins. A starving fish rolls over and turns pale during its rescue window. This update also improves save recovery and the fish catalog in crowded tanks. The playtest is in Simplified Chinese on Standard difficulty.

You can continue a valid v0.4.0 save in its existing slot. Players returning from chapter01-rc1 or earlier should start in an empty slot. Extract the full ZIP, then run `Aquarium Days.exe` on Windows or follow the bundled launcher instructions on Apple Silicon. The Mac build has not been tested on hardware and has no Developer ID signing or notarization.

Optional playtest data sharing is enabled by default. Turn it off in Settings → Playtest Data. Offline play and saving remain available. [Release notes](https://github.com/Er2u/Aquarium-Days/releases/tag/v0.4.1-pre-alpha)
