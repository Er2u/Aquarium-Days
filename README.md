## 下载、启动与存档

**存档（两个平台）**　旧版本存档无法继承，请从空槽新开一局。

**Windows x64**　完整解压到新文件夹，双击 `Aquarium Days.exe` 并保留附带文件。

**Apple Silicon Mac**　完整解压后运行 `Launch_Playtest.command`，或直接打开应用。脚本与应用使用同一常规存档位置。[Mac 启动说明](https://github.com/Er2u/Aquarium-Days/releases/download/v0.5.0-pre-alpha/README_M2_Playtest.md)

左键交互，数字键或小键盘 1–6 选择快捷栏，右键或 Esc 取消、返回。音量可在设置的音频页调整。

## 试玩数据

「分享试玩数据」默认开启，可以在 **设置 → 试玩数据** 关闭，重启后保留选择。收集有限的进度、功能使用、性能摘要与错误诊断，帮助定位卡点；不上传完整存档、自定义鱼名、账号或本机路径，使用随机安装与会话标识。

数据低频记录、后台上传，断网不阻止经营、保存或退出。关闭后停止采集与上传并清理本地待传队列，已送达的数据不会自动撤回。

## English

The **v0.5.0 pre-alpha** playtest rebuilds Chapter 1 from opening the shop to earning the second star. The new shop blueprint lets you choose upgrades, and the two nets let you collect bubbles or push them together to merge. After the second star, you can continue into the previous version’s association permit and three-star progression. The playtest is in Simplified Chinese on Standard difficulty.

**Start a new game in an empty slot on either platform. Saves from earlier versions cannot be carried over.** Extract the full ZIP, then run `Aquarium Days.exe` on Windows or follow the bundled launcher instructions on Apple Silicon. The Mac build has not been tested on hardware and has no Developer ID signing or notarization.

Optional playtest data sharing is enabled by default. Turn it off in Settings → Playtest Data. Offline play and saving remain available. [Release notes](https://github.com/Er2u/Aquarium-Days/releases/tag/v0.5.0-pre-alpha)
