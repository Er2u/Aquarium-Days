## 本次更新

- **试玩数据自动补传。** 使用新上传入口，连接故障时尝试备用线路；仍在本机的有效积压会自动补传，保留期限延长至 30 天，仍受容量上限约束。
- **短局也有进度摘要。** 约一分钟开始发送有效经营时长、星数、付款进度与当前任务。分享可在设置中关闭，断网不影响游玩与保存。
- **移除水族设备系统。** 正式 v0.4.1 设备目录本来为空，现役鱼、造景和有效进度仍可继续。第一章开放范围不变。

## 下载、启动与存档

**Windows x64**　完整解压到新文件夹，双击 `Aquarium Days.exe` 并保留附带文件。v0.4.0 / v0.4.1 玩家可从符合当前读取规则的原槽继续。十月的 chapter01-rc1 及更早版本仍需从空槽开局。

**Apple Silicon Mac**　完整解压后运行 `Launch_Playtest.command`，或直接打开应用。脚本与应用使用同一常规存档位置。[Mac 启动说明](https://github.com/Er2u/Aquarium-Days/releases/download/v0.4.2-pre-alpha/README_M2_Playtest.md)

左键交互，数字键或小键盘 1–6 选择快捷栏，右键或 Esc 取消、返回。音量可在设置的音频页调整。

## 试玩数据

「分享试玩数据」默认开启，可以在 **设置 → 试玩数据** 关闭，重启后保留选择。收集有限的进度、功能使用、性能摘要与错误诊断，帮助定位卡点；不上传完整存档、自定义鱼名、账号或本机路径，使用随机安装与会话标识。

数据低频记录、后台上传，断网不阻止经营、保存或退出。关闭后停止采集与上传并清理本地待传队列，已送达的数据不会自动撤回。

## 测试与反馈

欢迎继续反馈经营与操作手感。若试玩数据没有发送，请附设置页的最近发送状态、平台和版本；Mac 真机启动及上传仍需要实际样本。已被旧版清理的积压无法恢复，建议及时更新。

报告问题时请注明版本 `v0.4.2 pre-alpha`、平台、复现步骤，并附截图或短视频。[反馈页](https://github.com/Er2u/Aquarium-Days/issues)

## English

The **v0.4.2 pre-alpha** playtest covers Chapter 1 through the three-star award. This update repairs automatic playtest-data uploads with a new primary endpoint and fallback, extends valid local backlog retention to 30 days within existing capacity limits, and sends progress summaries after about one minute. It also removes the aquarium device system. The playtest is in Simplified Chinese on Standard difficulty.

You can continue a valid v0.4.0 or v0.4.1 save in its existing slot. Players returning from chapter01-rc1 or earlier should start in an empty slot. Extract the full ZIP, then run `Aquarium Days.exe` on Windows or follow the bundled launcher instructions on Apple Silicon. The Mac build has not been tested on hardware and has no Developer ID signing or notarization.

Optional playtest data sharing is enabled by default. Turn it off in Settings → Playtest Data. Offline play and saving remain available. [Release notes](https://github.com/Er2u/Aquarium-Days/releases/tag/v0.4.2-pre-alpha)
