## 本次更新

- **从第一封交付来信到三星授牌。** 首款后即可查看客单，决定留下家养小金鱼，还是把它交出去换取经营资金。小馆蓝图集中展示投资和星级进度，第一章三星授牌是本次内容终点。
- **观察每条鱼需要什么。** 鱼详情会说明舒适线、致病风险和受影响的原因。氧气和水质统计可查看最近三分钟的变化，帮助判断扩养或新增造景带来的影响。
- **动手处理剩食和水质。** 腐食会变厚，买刷子后可以按住来回刷。需要快速恢复水质时，可从水质卡的小桶或统计页换水，确认框显示费用和预计回升。
- **一星发现与新投资。** 海龟达到 Lv2 后可取得成长首珠，玩家可以花这颗珠子开启召唤书。蓝图增加喂养和养护工具，吐泡石会产生可收取的银币泡。

## 下载、启动与存档

**Windows：** 完整解压到新文件夹，双击 `Aquarium Days.exe` 并保留附带文件。**本版需新开存档，不能从 chapter01-rc1 继续。** 可以保留原有试玩目录和进度。

**Mac：** 完整解压 Apple Silicon 包，按[包内 Mac 说明](https://github.com/Er2u/Aquarium-Days/releases/download/v0.4.0-pre-alpha/README_M2_Playtest.md)使用 `Launch_Playtest.command`，或直接打开应用。脚本与应用共用常规存档位置。Mac 版未经真机验证。

左键交互，数字键或小键盘 1–6 选择快捷栏，右键或 Esc 取消、返回。音量可在设置的音频页调整。

## 试玩数据

「分享试玩数据」默认开启，可以在 **设置 → 试玩数据** 关闭，重启后保留选择。收集有限的进度、功能使用、性能摘要与错误诊断，帮助定位卡点；不上传完整存档、自定义鱼名、账号或本机路径，使用随机安装与会话标识。

数据低频记录、后台上传，断网不阻止经营、保存或退出。关闭后停止采集与上传并清理本地待传队列，已送达的数据不会自动撤回。

## 测试与反馈

这次内测请重点体验跳过一星入门、扩养与水质恢复、刷子、换水、统计页和后续评级。本次 Windows 自动冒烟使用隔离存档；上述界面没有在最终包中另做人工操作。高密度鱼群性能及长期经营平衡仍需更多反馈。

## English

The **v0.4.0 pre-alpha** internal playtest covers the first chapter through its three-star award. This update reworks star progression, the blueprint and customer orders, and adds fish-specific environment needs, resource charts, a scrubbing brush and paid water changes. The playtest is in Simplified Chinese on Standard difficulty.

Start a new save. Progress from the October 15 chapter01-rc1 build is incompatible. Extract the full ZIP, then run `Aquarium Days.exe` on Windows or follow the bundled launcher instructions on Apple Silicon. The Mac build has not been tested on hardware and has no Developer ID signing or notarization.

Optional playtest data sharing is enabled by default. Turn it off in Settings → Playtest Data. Offline play and saving remain available. See the [release notes](https://github.com/Er2u/Aquarium-Days/releases/tag/v0.4.0-pre-alpha) for details.
